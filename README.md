## Running the tests

From the project root, run:

python -m pytest -q

On this Windows setup, the interpreter may need to be called explicitly if `pytest` is not on PATH:

& "C:/Users/Owner/AppData/Local/Python/pythoncore-3.14-64/python.exe" -m pytest -q
